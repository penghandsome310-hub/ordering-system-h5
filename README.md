# 门店平板自助点餐系统 - H5网页版

## 📱 项目介绍

这是一个**纯前端H5平板点餐系统**，模仿海底捞门店平板点餐交互风格。本项目为**第一阶段产品**，使用纯HTML+CSS+JavaScript开发，数据存储在浏览器localStorage中，无需后端服务器。

### ✨ 主要特性

- 🍽️ **11个菜系分类**：豫菜、鲁菜、川菜、粤菜、苏菜、浙菜、闽菜、湘菜、徽菜、主食、饮品
- 📱 **平板横屏优化**：仿海底捞经典左右分栏布局
- 🛒 **完整点餐流程**：选桌 → 点菜 → 购物车 → 提交订单 → 查看订单
- 🏪 **商家后台**：菜品管理、订单管理、状态更新
- 💾 **本地数据存储**：使用localStorage，刷新页面数据保留
- 🎨 **暖色餐饮风格**：简约高级，招牌菜高亮，辣度图标

### 🔄 开发阶段

- ✅ **第一阶段（当前）**：H5网页版，可在浏览器直接打开测试
- 🔜 **第二阶段（规划中）**：复用相同业务逻辑，移植为微信小程序版本

## 🚀 使用方法（重要）

### 方法一：直接打开HTML文件（推荐）

1. **下载所有文件**到本地同一文件夹，保持目录结构不变
2. **双击打开 `index.html`** 文件，会在默认浏览器中打开
3. 开始体验点餐流程！

### 方法二：使用本地服务器

```bash
# 如果安装了Python 3
cd ordering-system-h5
python -m http.server 8000

# 如果安装了Node.js的http-server
npx http-server -p 8000

# 然后在浏览器打开：http://localhost:8000
```

## 📖 功能页面说明

### 1. 桌号选择页 (`index.html`)

- 显示1-20号桌的按钮网格
- 有未完成订单的桌台会有绿色标记和订单数量提示
- 底部提供"商家后台"和"清空所有数据"按钮

**操作流程**：点击桌号 → 进入点餐主界面

---

### 2. 点餐主界面 (`menu.html`)

**布局设计（仿海底捞）**：

- **左侧固定导航栏**：11个菜系按钮，点击切换右侧菜品
- **右侧菜品区域**：网格布局展示当前菜系的所有菜品
- **底部购物车栏**：固定在屏幕底部，显示已选菜品和总金额

**菜品卡片信息**：
- 菜品图片、名称、价格、简介
- 标签（招牌/微辣/特辣/素食）
- 辣度图标（🌶️ 数量表示辣度）
- 加减数量按钮

**购物车功能**：
- 点击购物车图标展开详细清单
- 可修改数量、删除菜品
- 显示订单总额和菜品总数

**操作流程**：
1. 左侧选择菜系
2. 右侧浏览菜品，点击"+"加入购物车
3. 点击购物车图标查看已选菜品
4. 确认无误后点击"提交订单"
5. 在弹窗中填写备注（可选）
6. 确认提交 → 订单保存成功

---

### 3. 本桌订单查看 (`orders.html`)

- 显示当前桌号的所有历史订单
- 订单统计：订单总数、待上菜数量、累计消费
- 每个订单显示：订单编号、下单时间、菜品清单、备注、总额、状态
- 订单状态：待上菜、已上菜、已结账

**操作**：
- 继续点餐：返回点餐主界面
- 返回选桌：回到桌号选择页

---

### 4. 商家后台管理 (`admin.html`)

#### **菜品管理标签页**

- 查看所有菜品列表（支持按菜系筛选）
- 添加新菜品：填写名称、菜系、价格、图片、描述、辣度、标签
- 编辑菜品：修改菜品信息
- 删除菜品

#### **订单管理标签页**

- 查看所有桌台的全部订单
- 筛选订单：全部/待上菜/已上菜/已结账
- 更新订单状态：
  - 待上菜 → 标记为"已上菜"
  - 已上菜 → 标记为"已结账"
- 订单详情：桌号、下单时间、菜品清单、备注、总额

## ⚠️ 当前限制（H5版本）

### 技术限制

1. **数据不可跨设备同步**：localStorage只在当前浏览器生效
2. **无法多端协作**：商家后台和客人点餐端无法实时同步
3. **数据易丢失**：清除浏览器缓存会导致数据丢失
4. **无真实支付功能**：只是订单记录，无支付接口
5. **图片使用外链**：依赖Unsplash图片服务（需联网）

### 业务限制

1. **无用户认证**：任何人都可以进入商家后台
2. **无订单打印**：不支持后厨打印小票
3. **无实时通知**：订单提交后不会通知后厨
4. **无数据分析**：没有销售报表和数据统计

## 🔜 第二阶段：微信小程序改造方案

### 技术迁移计划

| H5版本 | 小程序版本 | 改造方案 |

## 🛠️ 开发建议

### 如果你想修改菜品数据

编辑 `js/dishes-data.js` 文件，按照现有格式添加/修改菜品：

```javascript
{
  id: 39,                    // 唯一ID
  name: '红烧肉',           // 菜名
  category: '浙菜',         // 菜系
  price: 58,                // 价格
  image: '图片链接',        // 图片URL
  description: '描述文字',   // 简介
  tags: ['招牌'],           // 标签数组
  spicy: 0                  // 辣度(0-3)
}
```

### 如果你想修改配色

在各HTML文件的`<style>`标签中修改CSS变量：

```css
:root {
  --primary: #D97706;      /* 主色调 */
  --primary-dark: #B45309; /* 深色 */
}
```

### 如果你想增加桌号数量

修改 `index.html` 中的循环次数：

```javascript
for (let i = 1; i <= 30; i++) { // 改为30张桌
  // ...
}
```
